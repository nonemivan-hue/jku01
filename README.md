# Обработчик данных поставщика для загрузки в Комплекс

Программа с графическим интерфейсом (Windows): берёт данные из файла
поставщика (**DBF** или Excel) и переносит их в файл для загрузки в
Комплекс (**Excel** `.xls` / `.xlsx`), соединяя строки по столбцу `KOD`.

## Что делает программа

1. **Перенос данных** из столбцов `SUM_N1…SUM_N16`, `ZADOLG1…ZADOLG16`,
   `MZADOLG1…MZADOLG16` файла поставщика в соответствующие столбцы файла
   загрузки; соединение по `KOD`. Если нужного столбца нет в файле
   загрузки — столбец добавляется.
2. **DOGOVOR1…DOGOVOR16**: если в файле поставщика для блока заполнены
   и `GLAVA<N>`, и `SUM_N<N>` → ставится `1`, иначе `0`.
3. **Новый столбец** `Определять тариф по площади` со значением `1`.
4. **Отсутствие KOD у поставщика** → в `SUM_N/ZADOLG/MZADOLG` ставятся `0`,
   выводятся предупреждения со списком кодов («Код семьи не найден: …»).
   Если столбца `KOD` нет в файле для загрузки → сообщение
   «Код семьи не найден (в файле для загрузки отсутствует столбец KOD)».
5. **Дубликаты KOD у поставщика** → по каждому блоку берётся **наибольшее**
   значение `SUM_N` (для `MZADOLG` — тоже максимум).
6. **Отрицательная сумма**: если в `SUM_N<N>` файла поставщика значение
   отрицательное → в файл для загрузки переносится `0`.
7. **Текстовый формат** полей `RAION, KOD, ID_FIAS, ID_KLADR, PUNKT, STREET,
   HOUSE, KORP, FLAT, KOM, PERIOD` и `GLAVA1…GLAVA16` сохраняется.
8. **ZADOLG1…ZADOLG16**: если в `MZADOLG<N>` есть какая-либо информация
   (не пусто и не 0) → `1`, иначе `0`.
9. После обработки предлагается **скачать (сохранить) результат**; имя файла
   соответствует имени файла для загрузки
   (`<имя>_обработанный.xls(x)`; при отсутствии MS Excel результат
   сохраняется как `.xlsx`).

## Установка зависимостей (Windows)

1. Установите Python 3.10+ с https://www.python.org/downloads/
   (галочка **«Add Python to PATH»** обязательна; tkinter входит в комплект).
2. В папке проекта выполните в командной строке:

   ```bat
   python -m pip install -r requirements.txt
   ```

   Нужны всего два пакета: **openpyxl** и **xlrd** (чтение/запись Excel).
   Для чтения DBF-файлов встроенный читатель не требует зависимостей
   (библиотека `dbfread` при желании может быть установлена дополнительно —
   программа использует её автоматически).

### Ошибка «ModuleNotFoundError: No module named 'dbfread'»

Если у вас старая версия файла `app.py`, требовавшая `dbfread`:
обновите файл — теперь программа работает без него. Либо установите
модули той версией Python, которой запускаете программу:

```bat
python -m pip install xlrd openpyxl
```

Полезно знать: если на компьютере несколько версий Python, `pip` может
ставить пакеты не туда. Всегда используйте `python -m pip ...` тем же
`python.exe`, которым запускаете `app.py`. Кроме того, новая версия
`app.py` сама пытается установить недостающие модули при запуске, а при
неудаче показывает окно с готовой командой установки.

## Запуск программы

Вариант А — из исходников (двойной клик по `run.bat` или):

```bat
python app.py
```

Вариант Б — запускать собранный EXE (см. ниже).

### Порядок работы в интерфейсе

1. «Обзор…» → выберите **файл данных поставщика** (`.dbf`, `.xls`, `.xlsx`).
2. «Обзор…» → выберите **файл для загрузки в Комплекс** (`.xls`, `.xlsx`).
3. Нажмите **«Обработать данные»**.
4. По завершении подтвердите сохранение и укажите, куда **скачать**
   результирующий файл (имя по умолчанию совпадает с именем файла загрузки).

## Создание запускаемого EXE-файла для Windows

1. Установите зависимости (см. выше) — `pyinstaller` уже входит в
   `requirements.txt`.
2. Выполните в командной строке в папке проекта (или просто запустите
   файл `build_exe.bat` двойным кликом):

   ```bat
   python -m PyInstaller --noconfirm --onefile --windowed --name "Обработчик_Комплекс" app.py
   ```

   * `--onefile` — один исполняемый файл;
   * `--windowed` — без окна консоли (только графический интерфейс).
3. Готовый файл: `dist\Обработчик_Комплекс.exe`. Скопируйте его туда, где
   удобно работать (Python на целевом ПК не требуется).

Примечание: чтобы сохранить результат именно в формате `.xls` (Excel 97),
на компьютере должен быть установлен Microsoft Excel — программа
конвертирует файл через него. Без Excel результат будет сохранён в `.xlsx`
(это открывается в Excel без ограничений). Формат DBF читается автоматически
(кодировки cp866/cp1251/utf-8).

## Структура проекта

| Файл | Назначение |
|---|---|
| `app.py` | Программа (GUI + логика обработки) |
| `requirements.txt` | Зависимости |
| `run.bat` | Быстрый запуск GUI |
| `build_exe.bat` | Сборка EXE через PyInstaller |
| `*.DBF` | Пример файла поставщика |
| `*.xls` | Пример файла для загрузки в Комплекс |
